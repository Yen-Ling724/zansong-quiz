# 讚頌猜歌

福智讚頌多人猜歌遊戲。主持人用電腦（接投影或分享螢幕）播放讚頌片段，玩家用手機掃 QR code 加入搶答。

整個遊戲只有一個檔案：`index.html`。不需要架伺服器、不需要帳號。

**線上版：https://yen-ling724.github.io/zansong-quiz/**（主持人用這個網址開遊戲，手機掃 QR code 就能加入）

## 玩法

| 玩法 | 需要手機？ | 說明 |
| --- | --- | --- |
| 手機選擇題 | 要 | 四選一，答對且越快分數越高（500～1000 分）。全部人答完會自動揭曉。 |
| 手機打字 | 要 | 打出歌名，每題可以猜 3 次。數字、標點、括號不用管；四個字以上的歌名錯一個字也算對（例如「回向／迴向」）。 |
| 手機搶答鈴 | 要 | 手機上有一個大大的「搶答」按鈕。最先按的是回答順序 1，音樂和倒數會自動暫停讓他說出歌名；主持人按「答對」或「答錯」（鍵盤 O／X）。答錯就輪到回答順序 2，排隊的人都答錯了，音樂會繼續播，其他人可以再搶。越早按、答對分數越高。一隊共用一支手機也可以。 |
| 現場搶答 | 不用 | 主持人播歌，大家喊答案，主持人幫答對的隊伍按「＋」加分。沒網路連線元件時也能玩。 |

**主持人也一起答題**：在設定頁勾選後，主持人直接在電腦上點選項（或按鍵盤 1～4）、打字模式則在大螢幕下方輸入歌名，跟手機玩家一起排名。沒有其他玩家也能開始，可以一個人練習。（打字模式時大家看得到主持人打的字，想公平比賽的話主持人改用手機加入即可。）

主持人鍵盤快捷鍵：**空白鍵** 暫停／繼續、**Enter** 揭曉／下一題、**R** 重聽片段。

## 歌單

- **福智讚頌官網**：內建官網「線上聽」的 91 首（其中 34 首有鋼琴演奏版）。可以依字部篩選、勾選個別歌曲，或選「鋼琴演奏」當困難模式。音檔直接從官網播放，不會複製。
- **自訂歌單**：在設定頁貼連結，一行一首：
  - YouTube 影片：`https://www.youtube.com/watch?v=…` 或 `https://youtu.be/…`
  - YouTube 播放清單：網址有 `list=` 的清單頁，會整份匯入
  - Spotify 歌曲：`https://open.spotify.com/track/…`（Spotify 電腦版在歌單裡 Ctrl+A、Ctrl+C 可以一次複製全部歌曲連結）
  - MP3 直連網址
  - 想指定答案或起始時間：`藍空 | https://youtu.be/xxxx | 1:05`
- 歌名會自動抓，**抓到的是影片標題時請改成正確歌名**，這就是答案。
- Spotify 沒登入時只能播 30 秒試聽。主持電腦的瀏覽器先登入 open.spotify.com 就能播完整歌曲。

設定和自訂歌單會存在主持電腦的瀏覽器裡，下次打開還在。

## 放到網路上（手機才能加入）

手機必須打得開同一個網址，所以要把 `index.html` 放到網路上。以下任選一種，都免費：

**GitHub Pages**
1. 在 GitHub 建一個新的 repository（例如 `zansong-quiz`），上傳 `index.html`。
2. 到 Settings → Pages，Source 選 `Deploy from a branch`，Branch 選 `main`、資料夾 `/ (root)`，儲存。
3. 等一兩分鐘，網址會是 `https://你的帳號.github.io/zansong-quiz/`。

**Netlify Drop**
1. 打開 https://app.netlify.com/drop ，把整個資料夾拖進去。
2. 登入（免費帳號）後網址就會保留下來。

上線後，主持人打開網址按「我來主持」，大家掃 QR code 或打開同一個網址按「我要加入」輸入房號即可。

## 在自己電腦上試玩

直接雙擊 `index.html` 可以玩「現場搶答」，但 YouTube 影片需要用網址開啟。在這個資料夾開終端機執行：

```bash
python -m http.server 8000
```

然後打開 http://localhost:8000 。同一個 Wi-Fi 的手機要加入，需要用電腦的區網 IP（例如 `http://192.168.1.23:8000`），或直接用上線的網址。

## 常見問題

- **手機連不上房間**：確認房號；主持電腦的分頁不要關掉或重新整理（重新整理會換房號）。少數公司或學校網路會擋點對點連線，請手機改用行動網路試試。
- **主持人那邊沒聲音**：瀏覽器要先點過頁面才能播放，按「繼續播放」即可。
- **YouTube 顯示「不允許在其他網站播放」**：那部影片的上傳者關閉了嵌入播放，請換一部。
- **遠端（視訊會議）玩**：主持人分享螢幕時記得勾選「分享音訊」，玩家一樣用手機加入。

## 技術說明

- 連線：[PeerJS](https://peerjs.com/)（WebRTC），主持人的瀏覽器就是房間，玩家直接連線到主持人。只用到 PeerJS 公用伺服器做配對。
- QR code：qrcode-generator。
- 音檔：福智讚頌官網的 CloudFront 連結；YouTube IFrame API；Spotify Embed iFrame API。
- 歌單資料抓自 https://www.blisswisdom.org/teachings/praise （2026-11-16）。官網新增歌曲後，需要更新 `index.html` 裡的 `ZS` 清單。
